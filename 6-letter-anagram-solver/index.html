What is a 6 letter anagram?

A six-letter anagram is a six-letter word formed by rearranging exactly the same six letters. For example, LISTEN, SILENT and ENLIST use the same six letters in different orders.

How to solve a 6 letter anagram

Enter all six letters and keep the exact six-letter filter selected. The solver checks the available letters and returns matches without using any letter more times than it appears.

Use clues to narrow results

If you know part of the answer, add Starts with, Ends with or Contains. Use ? for a blank or unknown letter.

Exact anagrams vs shorter words

An exact six-letter anagram uses all six letters. If you switch the length filter to five or four letters, the tool will also show shorter words that can be made from part of the same rack.
