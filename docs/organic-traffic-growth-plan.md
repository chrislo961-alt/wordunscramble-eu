# Organic traffic growth plan — 22 October 2026

This plan covers seven workstreams across Untilza, LetterToolkit, WordUnscramble.eu, SoloCalcKit and SoloBizKit. Do not claim growth until Search Console confirms it.

## 1. GSC opportunities
- Connect each site's verified Search Console property using the read-only workflow already in this branch.
- Prioritize high-impression queries ranking 5–20 and optimize existing pages first.
- Weekly measurement: clicks, impressions, average position and CTR by page/query. Record a 28-day baseline.

## 2. Avoid search intent overlap
- LetterToolkit owns **word counter, character counter, case converter, text cleaning**.
- WordUnscramble.eu owns **unscrambling, word patterns, wildcard letter solving and game dictionaries**.
- Distinguish titles, H1 and primary navigation. Do not create duplicate landing pages on both domains for the same search term without different useful functionality.

## 3. Off-site discovery
- Create useful demonstrations and relevant citations on communities/directories that allow them.
- No bulk links, purchased placements or automated Reddit posting.
- Track referring domain, landing page and referral visits.

## 4. Relevant backlinks
- Pitch tools to educators, writing resource directories, puzzle communities, indie maker directories and small-business resource sites.
- Track accepted links and ensure each placement serves real users; never exchange money for undisclosed ranking links.

## 5. Technical verification
- Validate HTTP 200, indexability, canonical, robots, sitemap links, noindex rules, redirects, site navigation and page-rendered content.
- Read URL Inspection for representative pages; web-search visibility is NOT proof of full index coverage.
- Critical test for Untilza: compare generated sitemap page counts to indexed counts and inspect selected offset/date pages for thin duplication.

## 6. Localization
- Prioritize markets by actual GSC country and query data.
- Translate UI, number/date formatting, metadata and visible content as one unit.
- Confirm valid hreflang pairs; do not duplicate English pages under many language paths without localized value.

## 7. Shared reporting
- Weekly per-site report: clicks, impressions, CTR, ranking changes, top 10 landing pages, and work completed.
- Do not conflate an impressions rise with increased visits.
- 30-day targets: eliminate confirmed crawl/indexability blockers; ship 5 substantive improvements to already-visible pages; secure 3 relevant independently earned references. These are action targets, not traffic guarantees.

## Immediate editorial priorities
1. Untilza: Halloween (Oct 31), Black Friday (Nov 27), Christmas (Dec 25), New Year — improve seasonal discovery, source accuracy and useful sharing.
2. LetterToolkit: /word-counter/ and /character-counter/ — prove distinct utility, immediate input and strong internal links.
3. WordUnscramble: dedicated puzzle-focused tools rather than another generic writing toolkit.
4. SoloCalcKit: prioritize specific calculator intents once GSC data reveals ranking opportunities.
5. SoloBizKit: prioritize a few useful freelancer workflows with intent and data validation.

## Publishing gate
Any new content requires intent validation, a genuinely working useful tool or original information, fact check, canonical/indexability and peer review. No AI bulk publishing.

## External observations
- Untilza and LetterToolkit pages were discoverable in public search results on Oct 22, 2026; this does not establish their traffic.
- Live robots/sitemap endpoints could not be verified from the web inspection tool and must be checked by a browser or CI.
- GSC secrets have not been configured or tested and must not be committed to GitHub.
