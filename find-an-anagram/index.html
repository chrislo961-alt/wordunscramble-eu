How do I find an anagram?

Enter the letters you have, then review the longest results first. For an exact anagram, set the word length to the same number of letters you entered so shorter words are removed.

What is an exact anagram?

An exact anagram rearranges the same letters into another word without adding or removing letters. If you enter five letters, an exact result therefore needs to contain five letters built from that same letter set.

How do I narrow a large result list?

Use Starts with, Ends with, Contains or exact length when a puzzle gives you a known pattern. Use ? for an unknown letter or blank tile.

Find an Anagram vs. Anagram Solver

This page targets the simple task of finding an anagram from a supplied letter set. For broader explanations and more anagram workflows, use the main Anagram Solver.

FAQ

Can I find shorter words too?

Yes. Leave the length filter open or choose a shorter length to see words built from part of your letter set.

Can I use an unknown letter?

Yes. Enter ? for each unknown letter or blank tile.
