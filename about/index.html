About WordUnscramble.eu

WordUnscramble.eu is an independent English-language word utility built for fast letter puzzles, anagrams and pattern searches.

Word data

The current search index contains 194,152 simple alphabetic entries between 2 and 15 letters, derived from the open-source Wordnik wordlist. The Wordnik source is MIT licensed; the required license notice is included with the project files.

This site does not claim that every result is valid in every particular board game or tournament dictionary.
