What makes Word Finder different from the Unscrambler?

The main Unscrambler is designed for a fast answer from a rack of letters. Word Finder is the more flexible version: you can require a starting sequence, an ending, a contained sequence or an exact word length. That makes it useful when you already know part of the answer.

Useful examples

Searching LISTEN can return full anagrams such as SILENT and ENLIST as well as shorter words made from the same letters. If you need only six-letter answers, choose 6 letters. If the answer must start with S, add s under Starts with.

For a blank tile, replace the unknown letter with ?. A search such as QU?TZ asks the finder to test one wildcard alongside Q, U, T and Z. Blank letters score zero in the displayed point total.

When to use each word list

Common English is the best default because it favors familiar words and keeps noisy results down. Broad English offers maximum coverage, including uncommon or specialist entries. ENABLE is an open game-word lexicon and is useful as a separate reference, but it should not be treated as an official ruling for a branded game.

How the filters combine

Filters are cumulative. If you search letters STARE, choose 4 letters, set Starts with to s and Contains to t, the result must satisfy all of those conditions at once. If no words remain, remove the least certain restriction first.

FAQ

Can I use more than one wildcard?

Yes. Each ? or * represents one blank letter, up to the 15-character input limit.

Why do I see unusual words in Broad English?

The broad list is intentionally inclusive. For everyday answers, switch back to Common English, where less familiar entries are filtered out.

Are the point values official for every game?

No. The displayed values use standard English tile scores as a general guide. Different games and editions can use different scoring or dictionaries.

What if I know positions instead of a letter pool?

Use the Crossword Pattern Solver for patterns such as ?r?ne, or the Wordle Solver for five-letter clue states.
