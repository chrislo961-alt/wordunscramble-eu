What is a phrase unscrambler?

A phrase unscrambler takes the letters from a phrase and searches for words that can be formed from those letters. It is useful when a puzzle gives you a mixed-up phrase, a long letter set or several words whose spaces no longer matter.

How to unscramble a phrase

Remove spaces, punctuation and other non-letter characters, then enter the remaining letters above. Start with the longest results, then add an exact length, Starts with, Ends with or Contains filter if the puzzle gives you another clue.

Phrase unscrambler vs. phrase anagram solver

The terms overlap. A phrase unscrambler is a broad way to describe finding words from letters taken from a phrase. A phrase anagram solver is more exact when you want rearrangements of all supplied letters. This page supports both workflows, but it returns individual words rather than automatically assembling a complete multi-word anagram.

Tips for longer phrase searches

  • Start with uncommon letters because they reduce the number of plausible matches.
  • Use an exact word length when the puzzle gives a fixed answer size.
  • Use ? for an unknown letter or blank tile.
  • Use pattern filters only for letters or fragments you know are correct.
  • For a simple single-word rearrangement, the main Anagram Solver is usually faster.

Phrase Unscrambler FAQ

What is a phrase unscrambler?

It uses the letters from a phrase to find possible English words. Remove spaces and punctuation before searching.

Can I unscramble a phrase into several words automatically?

No. This tool currently returns individual words from the available letters; it does not automatically split the full letter set into a complete multi-word phrase.

Can I use a wildcard?

Yes. Enter ? for each unknown letter or blank tile.

Why might a result not work in a specific game?

Games can use different dictionaries and rules. See How Our Word Data Works and verify disputed words against the relevant game's official source.
