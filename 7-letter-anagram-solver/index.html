What is a 7 letter anagram?

A seven-letter anagram is a seven-letter word formed by rearranging exactly the same seven letters. Every letter count must remain unchanged.

How to solve a 7 letter anagram

Enter all seven letters and keep the seven-letter filter selected. The solver checks the available letters and returns exact-length matches first.

Use clues to narrow results

Add Starts with, Ends with or Contains when you know part of the answer. Use ? for a blank or unknown letter.

Exact anagrams vs shorter words

An exact seven-letter anagram uses all seven supplied letters. If you change the length filter to six, five or fewer letters, the tool will show shorter words made from part of the same rack.
