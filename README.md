# WordUnscramble.eu V1
Traffic-focused English-only foundation.

Included: working client-side unscrambler, wildcard, starts/ends/contains/length filters, sorting, Word Finder, Anagram Solver, 2-8 letter pages, Q/X/Z pages, word-list hub, trust pages, sitemap, robots and AdSense placeholder.

IMPORTANT: the included dictionary is deliberately compact for testing. Before serious launch, replace `data/words.txt` with a large legally usable English word list. Also replace the Contact placeholder with a real public contact method.

No server, AI API or Worker is required.
