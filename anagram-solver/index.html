What is an anagram solver?

An anagram solver finds words that can be formed by rearranging supplied letters. It is most precise when you need an exact rearrangement rather than any shorter word that can be built from the same letter set.

LISTEN and SILENT are exact anagrams because they use the same six letters in the same counts. LINE can be made from some of the letters in LISTEN, but it is not an exact anagram.

Anagram solver vs anagram finder

People often use anagram solver and anagram finder for the same task: entering letters and finding valid rearrangements. On this page, leaving the length filter open can also show shorter words made from part of the same letter set.

How do I find all possible words from my letters?

Enter the complete letter set and leave the length filter on Any length to see shorter matches as well as full-length rearrangements. If the puzzle requires every letter, set the result length to the same number of letters you entered.

How to find an exact anagram

Enter all confirmed letters and set the result length to match the input length. This removes shorter words and leaves candidates that use the full letter count.

How wildcards work in anagrams

A wildcard stands in for an unknown letter. Enter ? for each blank or missing letter and the solver will test possible substitutions.

Wildcards increase the number of possible results, so combine them with an exact length or another known clue when you want a tighter answer set.

Which word list should I use?

Common English is the best default for familiar words. Broad English increases coverage, while ENABLE is a public word list that can be useful as a separate reference.

No general list should be treated as an official ruling for every branded word game. Dictionaries, editions and regional rules differ. See How our word tools work for the site's word-list provenance and limitations.

Anagram Solver FAQ

What is an anagram solver?

An anagram solver finds words that can be made by rearranging supplied letters. For an exact anagram, the result uses the same letters in the same counts as the input.

Is an anagram solver the same as an anagram finder?

Usually yes. Both terms describe a tool that finds anagrams from supplied letters, although some finders also show shorter words made from part of the letter set.

How do I find all possible words from my letters?

Leave the length filter open to see shorter matches as well as full-length rearrangements. Set an exact length when every letter must be used.

How do I find an exact anagram?

Enter your letters and set the result length to the same number of letters. This filters out shorter words that do not use the full set.

Does the solver support blank letters?

Yes. Enter ? for each wildcard or unknown letter.

Can I solve a phrase anagram?

Are all results valid in every word game?

No. Dictionaries and game word lists differ, so verify disputed words against the official list or rules for the game you are playing.
