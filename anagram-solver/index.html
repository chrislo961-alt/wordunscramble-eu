How to solve an anagram

Type the letters you have and the solver checks which English words can be built from them. Results are grouped by length, so longer possibilities are easy to spot first. Add ? for an unknown letter.

Narrow the answer

If your puzzle gives you clues, use the advanced filters. You can require a word to start with certain letters, end with certain letters, contain a sequence, or have an exact length. This is useful for crosswords, letter puzzles and word games where part of the answer is already known.

Anagram examples

Letters such as stare can produce words including stare, rates, tears and other shorter combinations. The solver can use some or all of the supplied letters; if you need an exact same-letter anagram, focus on results with the same length as your input.

Anagram solver vs. word finder

Both tools work from letters. Use this page when your goal is an anagram or letter rearrangement. Use the Word Finder when pattern filters are the main goal, or the Word Unscrambler for a general letter search.

FAQ

Does the solver support blank letters?

Yes. Enter ? for each wildcard or unknown letter.

Can I search for an exact word length?

Yes. Open Advanced filters and choose a length from 2 to 15 letters.

Are all results valid in every word game?

No. Dictionaries and game word lists differ, so check the official list for a particular game when validity matters.

Anagram examples

LISTEN and SILENT are exact anagrams because they use the same letters the same number of times. Select an exact length to exclude shorter words.
